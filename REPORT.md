
# Отчёт по лабораторной работе №3

## 1. Данные и подготовка

В лабораторной работе использовались два набора данных.

**Набор данных Student Performance:**
- Целевая переменная: `Performance Index`.
- Признак `Extracurricular Activities` преобразован в числовой формат: Yes = 1, No = 0.
- Данные разделены на обучающую и тестовую выборки в соотношении 80/20.
- Для нормализации признаков использовались среднее значение и стандартное отклонение обучающей выборки.

**Набор данных German Credit:**
- Целевая переменная: `Creditability`.
- Первый столбец использовался в качестве целевой переменной, остальные — в качестве признаков.
- Данные разделены на обучающую и тестовую выборки в соотношении 80/20 с сохранением пропорций классов.
- Признаки стандартизированы на основе обучающей выборки.

## 2. Гипотезы и эксперименты

В работе были проверены следующие гипотезы:

1. Линейная регрессия с использованием градиентного спуска способна предсказывать Performance Index с небольшой ошибкой.
2. Собственная реализация логистической регрессии может показать качество, близкое к реализации sklearn.
3. Классические алгоритмы Decision Tree и KNN могут показать отличающиеся результаты на одной и той же выборке.

Для линейной регрессии использовался пакетный градиентный спуск.

Для классификации была реализована собственная логистическая регрессия с использованием сигмоидальной функции и функции потерь Binary Cross-Entropy.

Также были проведены сравнения с моделями LogisticRegression, DecisionTreeClassifier и KNeighborsClassifier из библиотеки sklearn.

## 3. Метрики

**Линейная регрессия**

Значение MSE на тестовой выборке:

- Test MSE: 4.0826

**Классификация**

| Модель | ROC-AUC | Accuracy | Precision | Recall | F1 |
|---|---:|---:|---:|---:|---:|
| Own Logistic Regression | 0.8081 | 0.77 | 0.8013 | 0.8929 | 0.8446 |
| sklearn Logistic Regression | 0.8086 | 0.77 | 0.8013 | 0.8929 | 0.8446 |
| Decision Tree | 0.6190 | 0.68 | 0.7714 | 0.7714 | 0.7714 |
| KNN | 0.7412 | 0.72 | 0.7692 | 0.8571 | 0.8108 |

Собственная реализация логистической регрессии показала практически такие же результаты, как LogisticRegression из sklearn.

Decision Tree показал наименьшие значения Accuracy и ROC-AUC среди сравниваемых моделей. KNN показал промежуточные результаты.

## 4. Выводы

В ходе лабораторной работы были реализованы собственные алгоритмы линейной и логистической регрессии с использованием градиентного спуска.

Для задачи регрессии получено значение MSE = 4.0826 на тестовой выборке.

Для задачи классификации собственная реализация логистической регрессии достигла Accuracy = 0.77 и F1 = 0.8446.

Результаты собственной модели оказались практически идентичными результатам LogisticRegression из sklearn. Это подтверждает корректность реализации на использованной выборке.

В проведённом эксперименте логистическая регрессия показала лучшие результаты по сравнению с Decision Tree и KNN по большинству рассмотренных метрик.
